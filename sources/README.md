# sources/

第1幕(researcher)が集めた一次ソースを置く場所です。`AGENTS.md` の「5. 作業場所の分離」の通り、ここは**コミットする**対象です(`work/` とは違い、git管理外にしない)。

## ファイル名

```
sources/YYYY-MM-DD-<slug>.md
```

- `YYYY-MM-DD` はリサーチを行った日(投稿予定日ではない)
- `<slug>` はテーマを表す短い英数字(例: `openai-api-update`)。半角小文字とハイフンのみ
- 1テーマ1ファイル。同じslugで複数回リサーチし直す場合は上書きしてよい(履歴はgitログに残る)

## 中身の形式

`.claude/agents/researcher.md` の出力形式に従う。

```markdown
# テーマ

## ソース1
- URL:
- 公開日:
- 発信元:
- 要点: 3行以内。必ず自分の言葉で書く(原文の転載はしない)
- 確度: 確定 / 発表のみ / 未確定

## ソース2
...

## 注意点
未確定情報や、解釈が分かれる点があれば明記する
```

- すべてのソースに公開日とURLが必須。**14日以内の一次ソースのみ採用**(`researcher.md` の採用基準を参照)
- 3件集まらない場合は無理に埋めず、PMに報告してテーマ変更を検討する(詳細は `researcher.md`)

## この後の流れ

`director`(第2幕)がこのファイルを読み、`work/<slug>/structure.md` に構成案を書く。
構成案の各スライドには、このファイルのどのソースを根拠にしたかを紐付ける(`researcher.md` / `director.md` 参照)。
