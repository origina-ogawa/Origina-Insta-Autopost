# カルーセル投稿 検収ルーブリック

目利き（inspector）はこの全項目を判定する。
**1項目でも NG があれば全体を不合格とする。** 総合点では判断しない。

---

## 1. 情報鮮度

| # | 判定内容 | 合格条件 |
|---|---|---|
| 1-1 | ソースの有無 | `sources/` に紐付くファイルが存在する |
| 1-2 | 公開日 | 全ソースが14日以内。日付が確認できないものは不可 |
| 1-3 | 一次性 | 公式ブログ / 公式ドキュメント / 論文 / 一次発表のいずれか |
| 1-4 | 件数 | 3件以上 |
| 1-5 | 紐付け | 各スライドに `source_ref` がある（フックとまとめを除く） |

**まとめ記事・個人の解説記事は一次ソースとして認めない。**

## 2. 文字量（読みやすさ）

| # | 判定内容 | 合格条件 |
|---|---|---|
| 2-1 | 見出し | 20字以内 |
| 2-2 | 本文 | 60字以内 |
| 2-3 | スライド総量 | 80字以内 |
| 2-4 | フォント | `tokens.json` の値から変更されていない |
| 2-5 | 改行 | 1スライドの本文が4行を超えていない |

**フォントを縮めて収めた形跡があれば即NG。**

## 3. 構成

| # | 判定内容 | 合格条件 |
|---|---|---|
| 3-1 | 枚数 | 8〜10枚 |
| 3-2 | フック | 1枚目に数字・意外性・問題提起のいずれかがある |
| 3-3 | 単一メッセージ | 1スライドで2つ以上の主張をしていない |
| 3-4 | 着地 | 最終スライドにまとめと行動喚起がある |

## 4. 表現の正確さ

| # | 判定内容 | 合格条件 |
|---|---|---|
| 4-1 | 留保 | 未確定情報に「〜とされています」等の留保がある |
| 4-2 | 断定 | 断定しているのはソースで「確定」のものだけ |
| 4-3 | 転載 | ソースの原文をそのまま写していない |
| 4-4 | 数値 | 数字はソースに記載のあるものだけ。概算を作らない |

## 5. デザイン

| # | 判定内容 | 合格条件 |
|---|---|---|
| 5-1 | サイズ | 1080×1350（4:5） |
| 5-2 | セーフエリア | 上下80px・左右60px に文字がかかっていない |
| 5-3 | はみ出し | テキストの折り返し切れ・見切れがない |
| 5-4 | 統一 | 全スライドで配色とレイアウトが揃っている |

---

## 判定の出し方

- 各項目に OK / NG と**根拠**を書く
- NG は「どのスライドの、何を、どう直すか」まで指定する
- ルーブリックにない理由で落とさない（気になる点は改善提案として PM へ）

## 3回ルール

同一 Issue で3回不合格になったら**そこで止めて PM に報告する**。
4回目を試みてはならない。
