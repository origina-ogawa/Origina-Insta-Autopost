# 記憶

AI社員が回を重ねるごとに賢くなるための蓄積です。
作業前に必ず読み、作業後に更新してください。

| ファイル | 内容 |
|---|---|
| `brand.md` | 社長の好み、トーン、使ってよい/悪い表現 |
| `decisions.md` | 過去の判断とその理由 |
| `learnings.md` | 失敗と気づき |

## 肥大化を防ぐルール

- 追記だけを続けない。**月1回、棚卸しのIssueを立てて整理する**
- 矛盾する記述を見つけたら、勝手に消さず PM に報告する
- 1ファイル200行を超えたら要約して古い記述を圧縮する

記憶は多ければよいものではありません。矛盾した記憶は判断精度を下げます。
