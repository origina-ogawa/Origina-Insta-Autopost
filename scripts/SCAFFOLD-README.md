# scripts

| ファイル | 役割 | 状態 |
|---|---|---|
| `emit-event.mjs` | エージェントが作業イベントを記録する | 実装済み |
| `hook-log.mjs` | hooks から自動で記録する | 実装済み |
| `detect-pending.mjs` | 未投稿の posts を検出する | **要実装** |
| `publish-instagram.mjs` | Graph API で投稿する | **既存リポジトリから移植** |
| `render.mjs` | テンプレートから画像を生成する | **既存リポジトリから移植** |

## 移植する既存資産

現行 `origina-autopost` の以下は、そのまま使えるはずです。

- Graph API の認証・トークン処理
- カルーセルの投稿処理（コンテナ作成 → 公開の2段階）
- 画像のホスティング（Graph API は公開URLからしか読めないため）

**変えるのはトリガーだけです。** スケジュール実行をやめ、`main` へのマージで発火させます。

## 実装時の注意

- 投稿間隔は数分以上空ける（連続投稿はスパム判定のリスク）
- レート制限の最新値は Meta の公式ドキュメントで確認すること
- 非公式APIやスクレイピングは使わない（規約違反・BANリスク）
