# 3Dオフィス表示層(viewer/) デスクグリッド化・命名・吹き出し再改修 設計メモ

作成日: 2026-08-14
関連: `docs/superpowers/specs/2026-08-14-office-viewer-ui-update.md`(前回の改修)、`viewer/README.md`

## 背景・目的

前回の吹き出しサイズ修正後も、実際に見てみると背景が文字よりまだ狭く、かつ形状も
ただの長方形で「吹き出しらしさ」が無かった。また、6卓が半円状に配置されているため、
右側に新設したサイドバー(アクティビティログ)の下に机が隠れてしまう問題がある。
これらに加え、AI社員に個人名を付けて画面に表示したいという要望を受け、以下3点を改修する。

1. 吹き出しのデザイン刷新(幅の再計算+角丸+しっぽ付きの吹き出し形状)
2. デスクレイアウトを横3×縦2のグリッドに変更し、PMの旧位置(奥中央)に
   ユーザー(社長)を表す「社長席」を新設。サイドバーに机が隠れないよう調整
3. AI社員6人に個人名を付与し、名札に「名前+役職」を表示

## ① 吹き出しのデザイン刷新

### 幅計算の見直し(`viewer/src/lib/bubbleSize.ts`)

現行の`computeBubbleSize`は全角・半角を区別せず「1文字=0.1」で幅を見積もっており、
日本語主体のメッセージでは常に幅が不足していた。全角文字と半角文字で重みを分けて
計算し直す。

- 全角文字(ひらがな・カタカナ・漢字・全角記号など、Unicode範囲で判定)の重み: `1.0`
- 半角文字(英数字・半角記号など)の重み: `0.55`
- 1重み単位あたりの幅(`FULLWIDTH_UNIT`): `0.17`(フォントサイズ0.15に対し、字間の
  余裕を持たせた値)
- 計算方法:
  - `weightedLength` = 文字ごとの重みの合計
  - `rawWidth = weightedLength * FULLWIDTH_UNIT + H_PADDING`
  - 幅は`MIN_WIDTH`〜`MAX_WIDTH`でクランプ(値は現行を維持しつつ実装時に見た目で微調整)
  - `charsPerLine`(重み換算)`= maxTextWidth / FULLWIDTH_UNIT`
  - `lineCount = ceil(weightedLength / charsPerLine)`
  - `height = lineCount * LINE_HEIGHT + V_PADDING`

既存の`BubbleSize`型(`width`/`height`/`maxTextWidth`)はそのまま維持する
(`SpeechBubble`側の呼び出し方は変えない)。

### 吹き出し形状の刷新(`viewer/src/scene/SpeechBubble.tsx`)

現行は`planeGeometry`の角ばった長方形。以下のように変更する。

- `THREE.Shape`で角丸長方形+下向きの三角形の「しっぽ」を持つ輪郭を組み立て、
  `ShapeGeometry`に変換して使う(角丸の半径は幅・高さに対して小さめの固定値、
  しっぽは吹き出し下辺中央からアバターの頭側に向けて突き出す小さな三角形)
- 形状は`width`/`height`が変わるたびに再計算が必要なため、`useMemo`でメモ化する
- 色(`bg`)・テキストの扱いは現行のまま(`meshStandardMaterial`+`Text`)
- 罫線(枠線)は付けない(既存の名札等もフラットな板のみで枠線が無く、
  全体のマットな低彩度デザインと統一するため)

## ② デスクレイアウトのグリッド化+社長席の新設

### グリッド配置(`viewer/src/theme.ts`の`DESK_POSITIONS`を変更)

半円配置をやめ、AI社員6人(PM含む)を横3列×縦2行のグリッドに配置する。
全員カメラの方を向くよう`rotY`を統一する(`Math.PI`、既存のpm/producerと同じ向き)。

パイプラインの流れ(幕1〜5+PM)に沿って、奥列(カメラから遠い行)→手前列
(カメラに近い行)、それぞれ左→右の順に配置する。

| 列(x) | 奥列(z=-3.5) | 手前列(z=1.0) |
|---|---|---|
| 左(x=-3.6) | researcher | inspector |
| 中央(x=0) | director | publisher |
| 右(x=3.6) | producer | pm |

具体的な`DESK_POSITIONS`値(すべて`rotY: Math.PI`):

```
researcher: { x: -3.6, z: -3.5, rotY: Math.PI }
director:   { x: 0,    z: -3.5, rotY: Math.PI }
producer:   { x: 3.6,  z: -3.5, rotY: Math.PI }
inspector:  { x: -3.6, z: 1.0,  rotY: Math.PI }
publisher:  { x: 0,    z: 1.0,  rotY: Math.PI }
pm:         { x: 3.6,  z: 1.0,  rotY: Math.PI }
```

既存の出社/退社アニメーション(`WALK_DIR`/`WALK_DISTANCE`)・handoff/rejectの
身を乗り出す演出(`LEAN_TO_NEXT`/`LEAN_TO_PREV`)は、いずれも`DESK_POSITIONS`から
自動計算される仕組みのため、上記の値変更だけで追従する(計算ロジック自体の
変更は不要)。ただし`PIPELINE_NEXT`/`PIPELINE_PREV`の対応関係(researcher→
director→producer→inspector→publisher)は変えない。

### 社長席の新設

PMの旧位置(半円配置時の奥中央、`x:0, z:-6.5`)に、ユーザー(社長)を表す
飾りの机を新設する。

- AI社員の一覧(`ACTORS`)には加えない。イベントログとは連動しない、常に
  そこにある固定オブジェクトとして実装する(`Office.tsx`に直接追加)
- 机自体は既存の`Desk`コンポーネントを流用してよい(実装時、通常の机とは
  区別がつく程度の見た目にするかは実装時の裁量とする。最低限、名札で
  「社長」と表示する)
- アバター(人物)は表示しない。空席のまま
- 名札は既存の`NameSign`と同様の見た目で「社長」とだけ表示する

### サイドバー(アクティビティログ)に机が隠れないようにする

新レイアウトは半円配置(x=±6.2)よりも横幅が狭い(x=±3.6)ため、多くの場合
サイドバー(画面右300px)の下に隠れなくなる見込みだが、確実にするため
`Scene.tsx`のカメラ位置・注視点を左寄りに調整する(目安: カメラ位置・
注視点ともにXを-2程度シフト)。正確な値は実装時にブラウザで見た目を
確認しながら微調整してよい。

## ③ AI社員への個人名の付与

`viewer/src/theme.ts`に新しい定数`ACTOR_NAMES`を追加し、各AI社員に個人名を割り当てる。

| actor | 名前(ひらがな表示) | 漢字(由来・ドキュメント用) | 由来 |
|---|---|---|---|
| pm | つかさ | 司 | 全体を取り仕切る役 |
| researcher | あかり | 灯 | 情報を照らして見つけ出す役 |
| director | ゆい | 結 | ソースを構成として結びつける役 |
| producer | たくみ | 匠 | 手を動かして作り上げる役 |
| inspector | さえ | 冴 | 鋭く厳しい目でチェックする役 |
| publisher | つばさ | 翼 | 世の中へ送り出す役 |

3Dの名札(`Office.tsx`の`NameSign`)は小さく視認性が優先されるため、
**ひらがな表記のみ**を3D空間に表示する(漢字は本設計書の由来メモに留める)。

名札の表示を「名前(大きめ)+役職(小さめ)」の2行構成に変更する。
既存の名札の板サイズ(`0.9 x 0.32`)では2行を収めるのが窮屈なため、
実装時に板サイズ・フォントサイズを調整してよい(例: 板を少し縦長にする、
または名前0.19/役職0.13程度の2段フォントサイズにする)。

## 動作確認方法

`npm --prefix viewer run dev` を起動し、`scripts/emit-event.mjs`で疑似イベントを
流し込みながらブラウザで確認する。

- 短いメッセージ・長いメッセージ(日本語中心)双方で、吹き出しの背景が文字を
  はみ出さず、かつ角丸+しっぽの吹き出し形状になっていること
- 6卓が横3×縦2のグリッドに並び、全員が同じ向き(カメラ側)を向いていること
- PMの旧位置に「社長」の名札を持つ空席の机があること
- どの机もサイドバー(右側のアクティビティログ)の下に隠れていないこと
  (ブラウザの画面サイズを変えても大きく崩れないか、可能な範囲で確認する)
- 各社員の名札に「ひらがなの名前」+「役職」の2行が表示されていること
- 既存の出社/退社アニメーション・吹き出し演出(面白いセリフ含む)・
  handoff/rejectの身を乗り出す演出が、新しい配置でも壊れていないこと

## スコープ外(今回はやらない)

- 社長席への実際のインタラクション(クリックで何か起きる等)
- AI社員の名前を`logs/events.jsonl`のスキーマやエージェント側の実装
  (`.claude/agents/*.md`等)に反映すること。今回はviewer(表示層)の
  見た目だけの変更であり、ログのactor名(`pm`/`researcher`等)は変更しない
